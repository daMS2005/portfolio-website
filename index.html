Model research · release

Triplet SAE Project

Compared LoRA fine-tuning with SAE feature steering to determine which technique was better for subject–predicate–object extraction used in Graph-RAG navigation.

Role, engineering details & stackHide project details

Research question Which approach performs better for Graph-RAG triplet extraction: LoRA fine-tuning or targeted steering through sparse autoencoder features?

  • Built comparable SAE-steering and LoRA fine-tuning workflows, then evaluated their subject–predicate–object extraction quality for downstream Graph-RAG traversal.
  • Fine-tuned Gemma 3 4B IT with LoRA and packaged deployment-oriented GPTQ 4-bit and 8-bit variants.
  • Ran the GPU-heavy analysis and training workflow on Google Cloud compute.

Interpretability infrastructure

OLMo SAE Builder

A readable, single-GPU pipeline for turning large text corpora into released sparse autoencoders for OLMo-3-7B-Think.

Role, engineering details & stackHide project details

Scope Data collection, activation infrastructure, SAE training, validation, and public model packaging.

  • Streamed Dolma and Dolci-Instruct-SFT data, captured residual activations with forward hooks, and wrote disk-backed chunks instead of loading the corpus into memory.
  • Trained TopK SAEs across four model layers on roughly 20 million token activations per layer and released seven SAELens-compatible artifacts.
  • Built and operated the Google Cloud GPU workflow needed to move data, run long jobs, preserve checkpoints, and publish the outputs.
