What is happening

Same behavior, different asset pipeline.

01

Read the pointer

Convert the cursor into a clean −1 to +1 coordinate inside the robot’s own stage.

02

Clamp the pose

Map that coordinate to small yaw and pitch limits so the character never twists unnaturally.

03

Damp each frame

Ease the current rotation toward the target with frame-rate-independent exponential damping.
