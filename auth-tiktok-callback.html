TikTok OAuth redirect

This URL (https://daniel-mora.com/auth/tiktok/callback) is a registered OAuth redirect URI for applications I develop that use TikTok’s developer platform (such as TikTok Login).

After authorization, TikTok redirects here with parameters documented in TikTok’s OAuth guide (for example code or error). The owning application completes token exchange securely on the server.

You can usually close this tab once authorization finishes in your app.
