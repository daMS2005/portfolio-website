Meta OAuth redirect

This URL (https://daniel-mora.com/auth/meta/callback) is a registered OAuth redirect URI for applications I develop that use Meta APIs (such as Facebook Login or Instagram).

If you were sent here during development or authorization, your browser may show query parameters appended by Meta (for example code or error). The owning application completes the flow server-side according to Meta’s OAuth documentation.

You can usually close this tab once authorization finishes in your app.
