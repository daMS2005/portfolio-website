Disclosure boundary

The public repository is intentionally not a runnable copy of the production system. It includes selected modules, tests, redacted configuration structure, and explanatory docs; it omits the entry point, dependency manifest, environment template, and most production modules.

Intentionally withheld. Prompts, tuned configuration values, production orchestration, resume and reuse machinery, provider integrations, research/search logic, the brand and animation system, and most of the TypeScript renderer and agent implementation.

The portfolio follows the same boundary. It demonstrates the system's scope and public evidence without reproducing the transferable implementation details.
